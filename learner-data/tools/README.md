# learner-data/tools

Инструменты для работы с карточками учеников. Только стандартная библиотека
Python 3.10+, ничего ставить не нужно. Все команды запускаются из корня проекта
и работают из любой папки.

| Файл | Что делает |
|---|---|
| `validate.py` | Проверяет каталог тем и все карточки: структуру, ссылки на темы, карту компетенций, согласованность статусов. |
| `zpd.py` | Правило ЗБР: считает зону по каждой теме из карты компетенций и объясняет, почему получилось именно так. |
| `build_context.py` | Компактная проекция карточки для ИИ-репетитора в чате. Полная карточка в модель не уходит. |
| `progress_report.py` | Отчёт о динамике за период: что выросло, где стало нужно меньше помощи, какие ошибки повторяются. |
| `learner_common.py` | Общие мелочи: загрузка JSON, регулярки, безопасное чтение карточки по id. |
| `selftest.py` | Тесты всего перечисленного. Запускается одной командой, ничего не требует. |

## Частые команды

```bash
# проверить все карточки; --strict считает предупреждения ошибками
python learner-data/tools/validate.py --strict

# где ребёнок сейчас и почему
python learner-data/tools/zpd.py zvezdin-artem
python learner-data/tools/zpd.py zvezdin-artem --format json

# перезаписать производный блок learner_model.zpd по карте компетенций
python learner-data/tools/zpd.py zvezdin-artem --write

# что уйдёт в модель при обычном вопросе ребёнка
python learner-data/tools/build_context.py zvezdin-artem

# полная карточка — только для педагога, в модель её передавать нельзя
python learner-data/tools/build_context.py zvezdin-artem --format json

# отчёт о динамике
python learner-data/tools/progress_report.py zvezdin-artem --since 2026-07-01

# тесты
python learner-data/tools/selftest.py
```

## Правила, которые проверяет валидатор

Кроме структуры карточки:

- `topic_id` существует в каталоге и не помечен устаревшим;
- в карте компетенций `mastery`, `independence`, `confidence` — числа от 0 до 1,
  темы не повторяются, уровни помощи в истории из известного списка;
- блок `learner_model.zpd` совпадает с выведенным из карты компетенций
  (иначе предупреждение с командой, как перезаписать);
- `knowledge[].status` не противоречит зоне: тема с оценкой не может быть
  `not_started`, а тема, которую ребёнок сам не делает, — `confident`;
- нигде нет ключа со словом `balance`: баланс баллов всегда считается по журналу;
- псевдонимы и `learner_id` уникальны, а фамилия и отчество не попадают в
  проекции для модели.

Ошибки блокируют работу с карточкой (RAG её не примет), предупреждения — нет.

## Чего тут нет

Числа `mastery` и `independence` обычно не проставляют руками: их пересчитывает
`TeachCopilot_RAG/pipeline/card_updater.py` по уровню помощи, который
понадобился ребёнку на занятии. Правило и лестница подсказок описаны в
[../../TeachCopilot_RAG/docs/ZPD_STAGE4.md](../../TeachCopilot_RAG/docs/ZPD_STAGE4.md).
