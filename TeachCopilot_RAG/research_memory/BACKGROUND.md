## План выполненного запуска v2

План предназначен для пользователя и объясняет порядок и цель этапов:

1. Повторить калибровку судьи в JSON mode на 12 известных синтетических примерах. Это проверит формат и способность отличать заранее заданные критические и приемлемые случаи. При провале gate основная оценка блокируется.
2. Если калибровка пройдёт gate, оценить 55 результатов локальной генерации со статусом `ok`. Девять записей ошибок генерации (`6 memory_error`, `3 action_error`) сохранить отдельно и показать как ошибки, без приписывания им verdict качества.
3. Сравнить четыре способа памяти – только профиль, хвост, резюме и структурированные наблюдения – по техническим сбоям и машинным оценкам. Дев-пилот не даёт основания выбирать победителя без проверки.
4. Пользователь вручную просматривает итоговые примеры и спорные случаи до любых выводов.
5. После стабилизации процесса подготовить отдельный независимый test на новых примерах, не использованных при калибровке.
