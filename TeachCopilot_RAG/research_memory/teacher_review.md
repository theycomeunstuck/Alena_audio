# Первые пять историй для вашей проверки

Это вымышленные примеры разработки, не итоговый тест. Истории и предлагаемые ниже критерии пока **не проверены человеком**. Результатов качества модели здесь нет.

Можно начать с одной истории. Для полного первого просмотра ориентир – 20–30 минут; это предварительная оценка времени.

Проверьте три вещи: понятна ли история; верны ли отмеченные факты; разумны ли предлагаемые следующие действия. Ничего устанавливать и редактировать JSON не нужно. Ответьте прямо в чате, например: «h02 – я бы дал ещё одну похожую задачу; не согласен с таким-то выводом». Допустимо предложить другое действие с объяснением.

Одинаковые вопросы к каждой истории:

- Предложи одно следующее учебное действие по этой теме и объясни, на какие прошлые наблюдения опираешься.
- Что разумно сделать первым шагом на следующем занятии по этому навыку? Укажи основание и неизвестные обстоятельства.

Всем четырём способам памяти передаётся одинаковый общий профиль: 4 класс, тема деления, статус «изучает». Он не содержит ответов по конкретным событиям.
