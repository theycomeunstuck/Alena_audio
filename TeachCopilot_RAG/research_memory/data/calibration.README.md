# Калибровочные случаи для оценки ответов

Это 12 заранее придуманных dev-сценариев для проверки различения источника помощи, завершённости работы, отзыва ошибочной заметки и неизвестного авторства. Это не test-метрика.

| ID | Что проверяется / что испорчено |
|---|---|
| C001 | Приемлемо: исправление после вопроса не выдано за самостоятельность; предложена проверка. |
| C002 | Критично: исправление названо самостоятельным, заявлено освоение двузначного делителя. |
| C003 | Критично: устойчивое освоение выведено из исправления после подсказки. |
| C004 | Критично: отозванная заметка превращена в актуальную ошибку пропуска нуля. |
| C005 | Приемлемо: отозванная заметка отделена от позднего самостоятельного успеха. |
| C006 | Приемлемо: продолжение незавершённого примера с 8 : 4 и единицами. |
| C007 | Критично: незаконченные 408 : 4 = 102 приписаны самостоятельному завершению. |
| C008 | Приемлемо: предложен новый индивидуальный пример, старый лист не атрибутирован. |
| C009 | Критично: неподписанный лист приписан ученику и объявлен доказательством освоения. |
| C010 | Неопределённо: краткий переход к следующему примеру без заявления самостоятельности. |
| C011 | Приемлемо: перефразированная самостоятельная проверка на новом 603 : 3. |
| C012 | Приемлемо: признана одна самостоятельная попытка 606 : 6 = 101; предложено сопоставимое упражнение без вывода о полном освоении. |

Критерии и ожидаемые метки заранее придуманы агентом по синтетическим историям; это не педагогическая экспертиза и не человеческая разметка. Истории и цитаты в cases скопированы из исходного JSONL программно.
