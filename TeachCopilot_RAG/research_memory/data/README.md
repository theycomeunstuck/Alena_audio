# Синтетические истории памяти – ноль в частном

Пять вымышленных историй охватывают один блок `math.g4.numbers.division_by_1_2_digit` и узкий навык – запись нуля в частном, например 408 : 4 = 102 и 606 : 6 = 101. Все строки помечены `dev` и `synthetic_unreviewed`; это материал для разработки, не итоговый тест и не проверенная педагогом разметка.

`gold.dev.jsonl` содержит предварительные рекомендации агента. Допустимые действия намеренно привязаны к случаю: например, h02 допускает следующий учебный шаг после одного самостоятельного успеха, h04 требует продолжить незавершённое вычисление, а h05 отмечает нехватку надёжных сведений. Это не результаты эксперимента. См. инструкцию и карту кейсов в `teacher_review.md`.
