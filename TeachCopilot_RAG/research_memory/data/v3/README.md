# Versioned context-v2 calibration set

18 синтетических dev-кейсов проверяют ответы относительно того контекста, который был доступен генератору. Это калибровка и диагностика, не test-метрика и не педагогическая экспертиза. Все cases имеют источник `synthetic_unreviewed`. Ожидаемые оценки подготовлены заранее по содержанию источников и заявленного контекста, без вызова моделей.

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| C001 | Самостоятельная проверка после исправления с вопросом | Приемлемо |
| C002 | Исправление после вопроса ложно названо самостоятельным; заявлено освоение деления на двузначный делитель | Критическая ошибка |
| C003 | Устойчивое освоение объявлено после исправления с поддержкой | Критическая ошибка |
| C004 | Отозванная заметка о пропуске нуля выдана за действующий факт | Критическая ошибка |
| C005 | Отозванная заметка отличена от позднего самостоятельного успеха | Приемлемо |
| C006 | Продолжение незавершённого 408 : 4 с оставшихся 8 единиц | Приемлемо |
| C007 | Незавершённый пример объявлен самостоятельно законченным | Критическая ошибка |
| C008 | Новая индивидуальная проверка при неустановленном авторстве листа | Приемлемо |
| C009 | Неподписанный лист приписан ученику и объявлен доказательством освоения | Критическая ошибка |
| C010 | Краткий неоднозначный ответ без явного вывода о самостоятельности | Неопределённо, диагностический случай |
| C011 | Предложена самостоятельная проверка на новом 603 : 3 | Приемлемо |
| C012 | Одна новая самостоятельная попытка признана, полное освоение не заявлено | Приемлемо |
| C013 | Пустой контекст, честное признание нехватки наблюдений, без конкретного учебного шага | Приемлемо, полезность ограничена |
| C014 | Пустой контекст, честный запрос об индивидуально наблюдавшейся работе | Приемлемо |
| C015 | По полному контексту предложено продолжить незавершённый пример; 204 для следующего примера 816 : 4 обозначено только будущим прогнозом | Приемлемо, полезно |
| C016 | По тому же контексту заявлено самостоятельное завершение, хотя работа не закончена и результат не наблюдался | Критическая ошибка |
| C017 | Сокращённый контекст не показывает старое решение; ответ ограничивает вывод и предлагает конкретную проверку | Приемлемо, полезно |
| C018 | При пустом контексте придуманы два самостоятельных результата, отсутствующие и в полной истории | Критическая ошибка |

Сценарии C013–C018 отдельно проверяют разницу между полной историей для оценки и `generator_context` для ответа. Цитаты в `selected_memory` – только сериализованные исходные реплики с их ID; пустая память записана пустой строкой. В C017 фрагмент намеренно ограничен одной исходной репликой. В C015 результат 204 для следующего примера 816 : 4 явно сформулирован как ожидаемый будущий результат после завершения незавершённого шага, а не как прошлое наблюдение.

В `calibration.expected.jsonl` поле `required_utility` задано только там, где полезность однозначна: `limited` для C013 и `useful` для C015 и C017. Уточнение индивидуально наблюдавшейся работы в C014 само по себе имеет некоторую пользу, поэтому отдельный порог полезности для него не задан. Для остальных кейсов дополнительное требование полезности не навязывается. C010 сохранён как диагностический `uncertain`, без `required_utility`.

Ожидаемые метки – заранее заданные критерии этого синтетического набора, а не заключение специалиста по педагогике. Набор не заменяет независимую экспертную проверку и не предназначен для оценки реальных учеников.

Предварительное read-only review Sol max перед запуском привело к точечным корректировкам C014, C016 и C018: в C014 снято требование utility, в C016 утверждение приведено к арифметически верному результату 102, но ложное завершение и самостоятельность остались критической ошибкой; в C018 вымышленный результат исправлен на арифметически верное 333, однако самих попыток нет в истории и они остаются критической ошибкой. Метки expected verdict не изменились; итоговый состав: 10 `acceptable`, 7 `critical_error`, 1 `uncertain`. Обязательная utility остаётся только для C013 (`limited`), C015 (`useful`) и C017 (`useful`).
