# Проверка памяти

Актуальные результаты, команды и ограничения: [отчёт интеграции](../../../nirs/25_memory_integration_results.md).

Проверки повторяются командой `.venv-local/Scripts/python.exe scripts/verify_memory.py`; полный набор с браузером – `.venv-local/Scripts/python.exe scripts/verify_local.py --ui`. Каждый прогон использует отдельную временную локальную БД. Оплачиваемый проход имеет отдельный конечный запуск и журнал; не повторяйте его автоматически.
