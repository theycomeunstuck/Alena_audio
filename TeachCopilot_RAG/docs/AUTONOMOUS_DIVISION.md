# Самостоятельная практика деления

Режим запускается только для ученической учётной записи и только при флаге
`LOCAL_AUTONOMOUS_DIVISION_ENABLED=1`. По умолчанию флаг выключен.

Первая версия использует положительные делимые до 999999, делители от 1 до 99
и точное деление без остатка. Делитель выбирается однозначным по умолчанию;
ученик может выбрать двузначный. Тип частного чередуется между обычным,
с внутренним нулём и конечным нулём. Сложность автоматически не повышается.

Проверка ответа, вопросы и подсказки рассчитаны арифметическим кодом. Один шаг
содержит вопрос, ответ, объяснение правила и отдельно запрашиваемый показ
только текущего шага. Подсказки не меняют шаг. Обычный текст не интерпретируется
как числовой ответ и не передаётся в поиск или генерацию.

Сессия хранит режим `autonomous_division`. Состояние между занятиями
восстанавливается только из проверяемой цепочки действий ученика. При неизвестном
результате запроса или исправлении записи продолжение блокируется, а старый шаг
не подставляется. Явная смена незавершённого примера сохраняется как прерывание.

Завершение такой сессии возвращает `job=null` и `job_id=null`. Режим не создаёт
задачу извлечения интересов или интерпретирующую память, не подтверждает
освоение компетенции и самостоятельность вне приложения.

Для проверки используйте `python scripts/verify_local.py --ui`. Проверка создаёт
временную локальную базу и удаляет только её. Вызовы генерации в сценариях
практики запрещены проверяющими адаптерами.
