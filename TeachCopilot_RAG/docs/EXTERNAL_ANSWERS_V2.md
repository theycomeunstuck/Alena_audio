# Явное разрешение внешних ответов v2

Конфигурация `local_app_external_answers_v2` включает внешние ответы только через файл, переданный в `TEACHCOPILOT_EXTERNAL_ANSWERS_CONFIG` или `AnswerAdapter.from_config`. Без пути внешний режим выключен. Формат v1 сохраняет прежние пределы $0.40 и 20 вызовов.

Формат v2 требует `budget_authorization_path` с активной квитанцией `teachcopilot_additional_budget_v5`. Проверяются точное содержимое конфигурации и SHA256 её файла, путь журнала, отпечаток конфигурации журнала, отсутствие блокировки и пределы интеграции $4 / 6 вызовов. Общий дополнительный пакет – $20: $16 / 126 вызовов оценки и $4 / 6 интеграционных вызовов. Переноса старого остатка нет.

Каноническая история включает шесть журналов: `pilot`, `structured_pilot`, `json_mode_pilot`, `context_v3`, `evaluation_v4`, `integration_v4`. На момент перехода они содержали 188 вызовов, из них 13 с неизвестным исходом, и консервативный расход $1.24050250000. Копии журналов из экспортов повторно не суммируются. Новый переход блокирует все шесть журналов; строки расходов и неизвестных резервов сохраняются. Прежний неиспользованный остаток $2.7594975 к новым $20 не прибавляется.

Источник тарифа – `GET https://spiderssense.com/v1/models`. Снимок от 22.10.2026: `.local/research_memory/spiderssense_catalog_20261022.json`, SHA256 `c672a4d7cdf6f6a13f79b67ddfc62353f6b5eae9ee4ed8e542a77f3e8c27d8b8`. Для `openai/gpt-6.1-sol` указаны $0.50 за миллион входных и $3 за миллион выходных токенов. Судья фиксируется с `reasoning_effort=medium` и `max_completion_tokens=8192`; интеграционные ответы ограничены 1536 выходными токенами. Клиент продолжает использовать консервативные множители и резерв до отправки HTTP. Отсутствие модели или тарифа останавливает переход.

`scripts/transition_memory_budget_v5.py` по умолчанию только проверяет состояние. Явный `--execute` создаёт `.local/research_memory/budget_v5_20261022/`, два новых SQLite-журнала, квитанцию и v2-конфигурацию. Повторный переход с существующим каталогом или журналом запрещён.

## Конечный интеграционный пакет

`scripts/check_memory_external_v2.py` сохраняет 12 заранее определённых синтетических сценариев. Сначала выполняются шесть ожидаемых локальных переходов: почта в текущей реплике, телефон в цитате, URL в материале, ключ в диалоге, частный медицинский рассказ и неоднозначная история с местом. Затем следуют шесть допустимых учебных ответов: ноль в частном, «хз», общий интерес и запрет сюжета, неизвестные условия помощи, один успех с дробями и короткий прогноз вывода Python.

В режиме `--execute` используются настоящие `OllamaRuntime`, локальный privacy checker `gemma4:12b` и штатный клиент провайдера. Условия маршрутизации сценария не передаются модели. Если локальный gate разрешил небезопасный сценарий, пакет сохраняет провал и перехватывает переход до платного резервирования; такой случай не считается успешным локальным ответом. Для каждого локального перехода проверяется отсутствие изменения счётчика провайдера. Для каждого внешнего ответа проверяются фактические HTTP-байты: текущая реплика, буквальная цитата, псевдонимы источников и отсутствие известных идентификаторов.

Runner требует уже созданный общий журнал локальных генераций `--budget-ledger`. Сам он не создаёт и не сбрасывает предел 160 генераций / 90 минут. `LOCAL_GENERATION_SCHEDULER_DSN` должен указывать на основную БД, где используются только штатные записи admission. Вызовы embeddings учитываются отдельно. Пакет не измеряет работу 20 пользователей.

```powershell
.venv-local/Scripts/python.exe scripts/check_memory_external_v2.py --output .local/product_sessions_v1/external-dry
$env:LOCAL_GENERATION_SCHEDULER_DSN = $env:DATABASE_URL
.venv-local/Scripts/python.exe scripts/check_memory_external_v2.py --output .local/product_sessions_v1/external-run01 --budget-ledger .local/product_sessions_v1/run01/local-generation-budget.sqlite3 --execute
```

Результаты сохраняются в новом каталоге: предварительно зафиксированные сценарии, конфигурация без содержимого ключа, отдельные ответы и ошибки, фактические HTTP-тела, исходные ответы провайдера, SHA256 и итоговый отчёт. Заголовки авторизации не записываются; возможное отражение ключа в ответе скрывается с сохранением SHA256 исходных байтов. Запросы не повторяются, JSON не исправляется, неизвестный результат остаётся в денежном резерве. Уже использованный шестизапросный журнал не запускается повторно.

Офлайн-проверка кода:

```powershell
.venv-local/Scripts/python.exe -m pytest tests/test_memory_budget_v5.py tests/test_external_answers_v2_runner.py tests/test_answer_adapter.py -q
```

Тестовые двойники используются только в этих офлайн-тестах. Документ описывает протокол; фактический успех конечного запуска устанавливается по его `report.json`.
