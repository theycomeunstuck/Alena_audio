# Индивидуальное задание на учебный проект

Два варианта заполнения предоставленного шаблона с темой «Исследование способов отбора и представления долговременной памяти образовательного ИИ-ассистента при подготовке следующего занятия»:

* `ИЗ_память_обобщённая.docx` – общие этапы исследования без привязки к конкретным технологиям, объёму данных и параметрам опыта.
* `ИЗ_память_стандартная.docx` – обычная академическая формулировка с вариантами памяти, критериями сравнения и проверкой переноса между учебными сессиями.

Оформление, реквизиты и подписи исходного шаблона сохранены. Группа, Ф.И.О., должность и подписи не заполнялись без предоставленных данных. Каждый вариант – одна страница. Исходный файл не изменён; проверка структуры и оформления отражена в `verification.json`.
