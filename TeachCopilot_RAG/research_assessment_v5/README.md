# Дополнительная автоматическая оценка v5

Пакет оценивает сохранённые ответы, не повторяя исходную генерацию. Замороженная реализация `research_memory/` и `.local/research_memory/final_v4_20261018/` читается без изменений. Это отдельная агентская оценка синтетических данных, не человеческая экспертиза.

Порядок фиксирован: продуктовый пакет завершается первым; затем восемь dev-вызовов, однократное решение о коррекции, freeze, одна калибровка 24 случаев. Только квалифицированный судья получает 94 технически принятых ответа. Все 128 исходных строк остаются в знаменателе, включая 34 технических отказа. Методы раскрываются только при агрегировании отчёта. Основная единица сопоставления – история, всего 16 историй.

Dev и heldout содержат разные новые источники; агент подготовил heldout отдельно. `prepare` фиксирует байты обоих наборов и закрытых expected до первого dev-вызова. Метки expected никогда не входят в HTTP-запрос. Коррекция допускается по восьми dev-ответам, без повторных dev-вызовов. После `freeze` промпт, код, рубрика, схема, модель, настройки, наборы и метки проверяются по хешам. Настройка по калибровке запрещена.

Судья: `openai/gpt-6.1-sol`, `reasoning_effort=medium`, `max_completion_tokens=8192`. Отдельная авторизация связывает полный конфиг, устойчивый журнал, $16 и 126 вызовов. Перед первой оплатой оператор сверяет свежий каталог и тариф провайдера. Денежная резервация клиента останавливает пакет раньше численного лимита. Неизвестные резервы не возвращаются. Автоматических платных повторов нет.

```powershell
python scripts/run_assessment_v5.py prepare --workspace .local/research_assessment_v5_20261022
python scripts/run_assessment_v5.py dev --workspace .local/research_assessment_v5_20261022
python scripts/run_assessment_v5.py dev --workspace .local/research_assessment_v5_20261022 --execute
# Просмотреть только dev/review.private.json и исходные dev/calls. При необходимости одна коррекция.
python scripts/run_assessment_v5.py freeze --workspace .local/research_assessment_v5_20261022
# При коррекции добавить --correction-note с конкретным обоснованием только по dev.
python scripts/run_assessment_v5.py calibrate --workspace .local/research_assessment_v5_20261022 --execute
python scripts/run_assessment_v5.py assess --workspace .local/research_assessment_v5_20261022 --execute
python scripts/run_assessment_v5.py report --workspace .local/research_assessment_v5_20261022
python -m unittest discover -s research_assessment_v5/tests -v
```

Без `--execute` оплачиваемая фаза только проверяет входы и показывает конечный объём; сеть не используется. `prepare`, `freeze`, `report` – локальные операции. Каталог подготовки и каждая фаза создаются эксклюзивно. Дополнительно новая авторизация хранит глобальные `assessment_v5_execution_claims`, запрещающие повтор той же фазы из другого каталога. После прерывания/ошибки не удалять claim для продолжения; сохранённый неизвестный исход требует разбора и остаётся конечным.

Каждый вызов сохраняет полный blind request, фактически отправленное HTTP-тело со схемой, необработанный ответ провайдера или HTTP-ошибку, текст completion, usage, настройки, ошибки и конечную отметку. Значения ключа не записываются; при эхе ключа ответ редактируется только ради удаления секрета и сохраняется хеш первоначальных байтов. Учебный JSON, цитаты и оценки никогда не исправляются. Runtime-результаты и ключи в Git не добавляются.

Проверка оснований требует все пять критериев с объяснением и буквальной цитатой, допустимые ID для каждой цитаты, отсутствие дубликатов/пустых оснований, строгий JSON и согласованные вердикты. Буквальность – точное вхождение символов, без нормализации пробелов. Для калибровки обязательны все 24 оценки, все восемь критических ошибок, все восемь допустимых ответов, все обязательные utility и существенные предзаданные основания. Verdict неопределённых случаев диагностический; обязательная utility проверяется независимо.

При провале калибровки основная оценка блокируется. Пакет сохраняет отрицательный результат и создаёт `human_review/packet.md` с прежними пятью историями t02, t04, t07, t10, t12, первым запросом и 20 местами. Названия методов и раскрытие находятся отдельно в `mapping.private.jsonl`. Человеческий просмотр при этом не объявляется выполненным.

Отчёт разделяет технические отказы, покрытие, существенные искажения, полезность, пять критериев и расходы. При непрошедшей калибровке содержательное покрытие остаётся 0/128; нулевые счётчики не доказывают отсутствие ошибок. Результаты нового журнала не суммируют старые копии журналов; прежние расходы и неизвестные резервы сохранены отдельным переходом бюджета.
