# Новые синтетические случаи дополнительной оценки v5

Набор подготовлен агентом до оценочных вызовов. Истории, ответы и ожидаемые метки синтетические и не проходили содержательную проверку человеком. Это проверка нового автоматического протокола, а не педагогическая экспертиза и не измерение результатов обучения детей.

`dev.cases.jsonl` содержит восемь новых ситуаций разработки, по одной на каждый тип. `dev.expected.private.jsonl` содержит их закрытые агентские метки. Разрешены восемь оценочных вызовов и одна корректировка нового протокола по этому набору. Сами случаи не являются ответами исходного исследовательского опыта.

`calibration.cases.jsonl` содержит 24 новых отложенных случая: по допустимому, критически ошибочному и неопределённому варианту каждого из восьми типов. `calibration.expected.private.jsonl` хранит закрытые ожидаемые метки. Источники отложенных случаев отделены от dev и от замороженного v4; каждый случай имеет собственные ID и отдельные тексты. Порядок 24 случаев перемешан с фиксированным seed `20261022` до запуска. Повторной настройки по калибровке и второй калибровки не предусмотрено.

| Тип | Проверяемое различие | Dev |
| --- | --- | --- |
| `teacher_review` | Просмотр рекомендации преподавателем совместим с наблюдавшейся самостоятельной попыткой | D501 |
| `unknown_help_conditions` | Верный итог не устанавливает условия помощи; непустой `unknowns` не оправдывает ложную самостоятельность | D502 |
| `empty_unknowns` | Пустой массив допустим, если для конкретного следующего шага нет существенного неизвестного | D503 |
| `record_correction` | Явный отзыв ошибочной заметки меняет источник; это не исправление учеником своего решения | D504 |
| `observed_progress` | Новый самостоятельный успех сохраняет факт прежней помощи и допускает локальный вывод о прогрессе | D505 |
| `single_success_generalization` | Один успех допускает соразмерную следующую проверку, но не доказывает устойчивую компетенцию | D506 |
| `interests_and_boundaries` | Интерес влияет на оформление, явный запрет сюжета обязателен, неясный выбор остаётся неясным | D507 |
| `topic_separation` | Успех и незавершённый шаг другой темы не подменяют состояние текущей темы | D508 |

Все случаи используют полный синтетический первичный источник и тот же текст в выбранном контексте генератора. Профиль повторён в истории и контексте без изменения. `review_required` во всех ответах равен `true`. В payload нет ожидаемых меток, типа ситуации или названия метода памяти. Судье разрешено передавать только payload; закрытые файлы и `situation_type` не входят в его запрос.

В ожидаемых строках `evidence_turn_ids` задаёт минимальные существенные основания известной метки – один или два источника. Это не перечисление всех доступных реплик. Допустимость всех фактически процитированных ID и буквальность выдержек проверяются отдельно по первичной истории. Исходные ответы, цитаты и JSON судьи не исправляются.

Для допустимых вариантов обязательна полезность `useful`; для критических – `limited`. В неопределённых вариантах источники содержат неразрешённую отсылку или противоречие, а ответ не определяет проверяемое следующее учебное действие; обязательная полезность – `uncertain`. Их verdict служит диагностикой. Квалификационный барьер отдельно требует оценки всех 24 случаев, обнаружения всех восьми обозначенных критических ошибок, принятия всех восьми допустимых ответов, совпадения обязательной полезности и прохождения проверок оснований.

До начала калибровки код, промпт, рубрика, модель, настройки и эти файлы должны быть зафиксированы общим манифестом нового пакета. Этот README не подтверждает прохождение калибровки или выполнение платных запросов. Файлы `research_memory/**`, результаты генерации исходных 128 строк и прежние калибровочные случаи здесь не изменялись и не использовались повторно как новые случаи.
