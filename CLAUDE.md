# Память репозитория TeachCopilot

## Зависимости и Python

- Для `TeachCopilot_RAG` используй Python 3.12 и `uv`. Источники зависимостей – `TeachCopilot_RAG/pyproject.toml` и `TeachCopilot_RAG/uv.lock`.
- Из каталога `TeachCopilot_RAG` подготавливай воспроизводимое окружение командой `uv sync --locked`, запускай команды через `uv run --locked`, например `uv run --locked python -m pytest tests/test_json_rag.py -q`. Для тестов используй `python -m pytest` – так корень приложения доступен при импортах.
- Для новой зависимости используй `uv add <пакет>`, для зависимости разработки – `uv add --dev <пакет>`. Проверяй и сохраняй соответствующие изменения `pyproject.toml` и `uv.lock`. Не заменяй это случайной установкой через системный `pip`.
- `torch` уже указан в зависимостях; в конфигурации `uv` для него задан CPU-индекс PyTorch. Отсутствие библиотеки в отдельном окружении само по себе не означает, что её нужно заново добавлять в проект.
- `tzdata` нужна для часовых поясов Windows. `playwright` и зафиксированный `mem0ai` относятся к зависимостям разработки и проверкам; их установка не включает экспериментальный Mem0 в продукте.
- Для браузерных тестов установи Chromium через `uv run --locked python -m playwright install chromium` и используй один и тот же `PLAYWRIGHT_BROWSERS_PATH` при установке и запуске. Часть тестов по умолчанию ищет браузер в `TeachCopilot_RAG/.local/ms-playwright`; установка в общий кеш сама по себе не меняет этот путь.
- Не перезаписывай и не синхронизируй существующее пользовательское окружение без необходимости. Для отдельной проверки можно задать `UV_PROJECT_ENVIRONMENT` с новым путём и выполнить `uv sync --locked`. Загрузка полной среды может быть большой.
- Корень репозитория также содержит отдельные `requirements_*.txt` для аудиочасти. Не переноси их автоматически в `TeachCopilot_RAG`; для задач с этими файлами используй отдельное окружение и `uv pip` с явным `--python`.
